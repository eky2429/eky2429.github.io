Overview

This was the first project I had for CS 211 (back when it was as easy course). At first I felt a little overwhelmed -- since it was my very first project in the class. However, I was able to push through (as a 1st year student), and I was able to complete the project!

Anyway, the details of the project are straight forward: it intially prints text welcoming the user to the game, and then it prompts the user to enter a command (a letter if you will), which will allow the user to either move the player to a different room, dispay instructions or give the player a chance to guess where the wumpus is. The game ends when the player either guesses correctly, or if the player enters a room with the wumpus in it -- which in this case is a game over!
