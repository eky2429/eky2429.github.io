Gerrymandering Analysis App

A data-driven C++ application that parses US Census and election data to mathematically identify gerrymandered districts using the "Efficiency Gap" metric.

Overview

The Gerrymandering App is a tool designed to analyze democratic health by examining electoral district fairness. By loading large datasets of district-level vote counts and eligible voter populations, the program identifies whether a state's district map is mathematically skewed to favor one political party.

I built this to practice handling structured data and complex file I/O. The app allows users to search for specific states and generate visual "plots" of the voting distribution across every district in that state.

Key Features

  • Multi-File Data Integration: Successfully synchronizes data between disparate files (districts vs. eligible voters) using state-name matching logic.
  • Efficiency Gap Calculation: Implements the legal/mathematical standard for identifying gerrymandering by calculating "wasted votes" for both parties.
  • Terminal-Based Plotting: Generates a text-based histogram (using 'D' and 'R' characters) to visualize the proportional split of voters in each district.
  • Interactive Command Interface: Features a custom command parser supporting load, search, stats, and plot functionalities.

Technical Details

  • Nested Struct Architecture: Utilized a StateInformation struct containing a custom vector of DistrictInformation structs to manage hierarchical data.
  • String Parsing: Developed robust CSV parsing logic using substr and find to extract data from comma-delimited text files.
  • Mathematical Modeling: Automated the 7% Efficiency Factor threshold—a standard benchmark used to determine if a state is legally considered gerrymandered.
  • Input Normalization: Implemented case-insensitive search logic to ensure user input (e.g., "illinois" vs "Illinois") always returns the correct state data.

Challenges & Solutions

The Problem: The district data file was formatted inconsistently, with some states having only one district and others having over fifty, all listed on a single line with varying numbers of commas.

The Solution: I developed a dynamic while loop with an internal switch state. This allowed the program to continuously "shrink" the input string as it parsed, identifying the pattern of (District Number, Democrat Votes, Republican Votes) regardless of how many districts a state actually possessed.

What I Learned

  • Algorithmic Thinking: Translated the sociological concept of "Wasted Votes" into a C++ function that handles both winning and losing vote scenarios.
  • Object-Oriented Design: Improved my ability to organize data by using constructors to initialize default values, preventing "garbage data" from affecting calculations.
  • File Stream Management: Gained experience in managing ifstream states, ensuring files are properly opened, read to EOF, and closed to maintain system resources.

Future Improvements
